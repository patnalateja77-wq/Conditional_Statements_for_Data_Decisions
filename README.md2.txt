Conditional Statements for Data Decisions

Project Overview

This project demonstrates how Python conditional statements are used to make decisions based on numerical and categorical data. It includes examples using "if", "elif", and "else" statements, along with multiple conditions using "and" and "or".

Objective

To understand and implement conditional logic in Python for data classification and decision-making.

Tools Used

- Python
- Jupyter Notebook
- GitHub

Topics Covered

- "if", "elif", and "else" statements
- Comparison operators (">", "<", "==", ">=")
- Logical operators ("and", "or")
- Positive and negative number identification
- Even or odd number checking
- Student pass/fail and grade classification
- Voting eligibility
- Largest number identification
- Temperature classification
- Employee salary classification
- Attendance eligibility
- Discount calculation
- Student performance classification

Program Description

The program contains more than 10 examples of conditional statements. It uses different conditions to classify data and make decisions.

A student performance classification example categorises students based on their marks as Excellent, Good, Pass, or Fail.

A discount calculation example determines the discount amount and final purchase price based on the purchase value.

How to Run

1. Install Python and Jupyter Notebook.
2. Open the "Conditional_Statements.ipynb" file.
3. Run each cell using "Shift + Enter".
4. Check the output of each example.
5. Modify the input values to test different conditions.
